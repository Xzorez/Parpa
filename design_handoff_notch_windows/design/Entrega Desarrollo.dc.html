Parpa — especificación para desarrollo

Todo lo necesario para construir la app nativa a partir del prototipo: medidas, colores, tipografías, animaciones, sonidos, comportamiento y las APIs de Windows que sustituyen a lo que en web solo era simulado. Tecnología recomendada: WinUI 3 + C# (.NET 8).

Prototipo → Ajustes → Bienvenida y bandeja →

01 · Por qué WinUI 3

WinUI 3 / C# — recomendadoAcceso directo a medios, notificaciones, audio, energía y red. Memoria baja (~60–90 MB), arranque rápido, composición nativa para animar.
Tauri — alternativaReutiliza el HTML del prototipo. Requiere puente en Rust para cada API del sistema; WebView2 añade ~100 MB.
Electron — descartadoDemasiado pesado para algo que vive siempre abierto (150–250 MB).

07 · Sonidos

Sintetizados, sin archivos. Cada tono: oscilador → ganancia con ataque de 5 ms y caída exponencial a 0,0001. Ganancia final = nivel × volumen global (60 % por defecto). Pulsa para oírlos.
